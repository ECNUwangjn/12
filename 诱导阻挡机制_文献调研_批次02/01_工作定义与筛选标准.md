## 用户确认的工作定义
靶蛋白 T 上有正常的底物结合/催化区域，以及另一个能够结合配体 L 的位点。L 单独结合 T 时不影响其功能；将 L 与另一蛋白 R 的配体连接后，形成 T–双功能分子–R 三元复合物，借助 R 的体积遮挡底物结合或进入，从而抑制 T。

“诱导阻挡机制”是本项目的工作名称；本记录不主张该名称或机制的学术首创性。

## 严格条件
1. 直接结合：有可信的 T–L 结合证据；区分亲和力、竞争IC50、共价标记率及细胞占有率。
2. 位点属性：L 不占据活性、底物识别、辅因子、已知调控/变构或天然必需PPI位点。非催化残基、非ATP竞争、非抑制性不等于非功能位点。
3. 单配体功能：在合理占有率和相关实验条件下，L 不抑制、不激活，也不明显改变所考察的功能。无实验≠功能阴性；单个终点无显著差异≠证明完全无效。
4. 诱导阻挡：T–双功能分子–R 的构象有可能阻碍底物进入或结合。只有三元形成、增强亲和力或蛋白降解均不构成阻挡证据。
5. 几何与可实现性：有适当的连接出口、R定位与丰度、蛋白完整构象及底物路径信息。

对“非功能”只作证据范围内的结论：目前未识别功能 / 在已测功能中未见作用 / 已知功能性位点。不能证明绝对无任何生物学作用。

## 位点证据优先级（与功能证据分开）
S1：T–所讨论配体的实验共结构（PDB）；记录蛋白构建体、物种、突变、配体ID、链和残基编号、分辨率、结构版本、电子密度/验证情况。
S2：定位突变 + 结合变化；必须检查突变体折叠、稳定性和基线功能，且区分蛋白位点突变与配体结构变化。
S3：共价质谱定位、蛋白NMR、HDX-MS、交联等定位证据；记录空间分辨能力。
S4：竞争、SAR或生物物理间接推断。
S5：仅 docking / AlphaFold / 未定位结合。
无配体apo PDB、其他配体PDB、同源蛋白PDB只能作结构背景，不能冒充S1。
结构确定“在哪里”；功能实验和遗传学确定“有什么作用”。PDB本身不能证明非功能。

## 候选标签
A：位点明确，排除了已知功能位点，且单体配体功能阴性证据充分；几何单独评级。
B：结合和功能阴性有依据，位点未知/非功能属性未证实。
C：可信fragment或弱配体，或功能数据仍不足；允许优先推进结构清楚的C类。
X：所查配体/位点已有直接功能作用、不符合化学类型/构建体条件等。只排除该配体–位点路线，不以一条反例淘汰整个靶点。
R：仅机制参照，不能算合格候选。
几何：G0未评估；G1仅文献描述邻近/合理推测；G2原文作者完成结构分析并提出可实现遮挡姿态；G3原文已有实验支持诱导阻挡。所有等级只评价文献，不能冒充本项目的结构分析。
化学类型另记：常规小分子 / 共价小分子 / fragment / 环肽 / 蛋白或适配体。环肽属于拓展化学空间，抗体/适配体仅作参考，未经用户扩展不计入小分子首选。

优先酶及明确底物体系；PPI识别蛋白、核受体、E3作为扩展池，必须说明与“底物口袋”原始范围的差异。
100是覆盖计划数，不是已经完成搜索数。逐项标记：待检索 / 已初查 / 原文初审 / 待补充材料 / 结构复核 / 暂停或排除某路线。
每批优先深挖有证据线索，必要时调整后续顺序；不因找到1个候选便停止其他类型覆盖。
完成本轮后保存进度，后续批次从continuation记录继续；没有设置定时或后台自动运行。

## 证据保存
每条重要事实标注来源与正文/图表/补充材料位置；区分原文事实、我们的推断、未核实事项和冲突。
保留检索日期、检索式、命中来源、无结果与访问限制。二手综述/供应商仅用于线索发现；结论尽量回溯原始研究。
不将网页抓取日期当发表日期；日期以原始文献元数据为准。
将证据缺失与访问失败分开：无法访问补充材料不等于材料不存在。

## 决策门槛
先审结合、位点功能属性、单配体效应三个硬门槛，再比较几何；分数不能抵消硬缺口。
可逆配体：仅在简单1:1平衡且游离浓度已知时估算占有率；低于Kd的阴性结果说服力弱。
共价配体：以时间/浓度相关的真实标记率评估，不套用可逆Kd公式。
小底物酶活、肽底物、全长蛋白底物、细胞功能分别记录。
终点优先是1个严格配对；若没有，给出最接近的B/C候选及最小补证据路径，明确“尚无严格合格者”。

## 后续机制验证原则
比较L、双功能分子、R配体、未连接的两种配体混合物，并在有无R情况下测功能。
用失活结合对照或竞争/遗传手段验证R依赖，监测T丰度与定位。
对不同大小的底物及底物浓度进行比较；仅凭动力学变化仍不能独立证明物理遮挡。
最终需要结构/空间证据支持，并排除聚集、降解、变构和定位改变等解释。
