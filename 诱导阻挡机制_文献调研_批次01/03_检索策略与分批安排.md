# 检索策略与执行顺序｜仅文献
更新日期：2026-10-26

## 双向检索
一条从目标蛋白、基因名、别名和亚型出发；另一条从配体特征、筛选方法和机制出发。不能只搜target＋inhibitor，否则会系统性遗漏无功能配体。
跨靶点关键词命中只增加线索；没有核查原文的靶点不计为完成。

## 关键词库
### 直接寻找silent binder
- "silent binder" / "silent binding" / "functionally silent"
- "non-inhibitory ligand" / "noninhibitory ligand" / "non-inhibitory binder"
- "non-modulatory ligand" / "innocent ligand"
- "binding without inhibition" / "binds without inhibiting"
- "does not inhibit" + binding / affinity / ligand / enzyme
- "no effect on activity" + binding / crystal / fragment
“不抑制”需要再查是否激活；“无细胞效应”需要再查细胞占有；不把关键词标签作为证据。

### 从位点与结构文献发现
- "non-functional binding site" / "non-functional pocket"
- "surface pocket" / "secondary binding site" / "distal pocket"
- "fragment screening" + crystal / NMR + secondary / surface / distal
- "crystallographic fragment" + activity / inhibition
- "novel binding site" + "no inhibition"
- "cryptic pocket" + ligand + function
新口袋、次级口袋、cryptic pocket均不等于非功能位点。不要在检索中完全排除allosteric：一些作者用该词泛指远端结合，需读正文判断。

### 从保留酶活的招募用途反查
- "non-inhibitory recruiter" + kinase / phosphatase / deubiquitinase
- DUBTAC + ligand + noninhibitory
- PHIC / PHICS / PHORC + ligand + non-inhibitory
- "functional screening" + "innocent ligands"
- "on-bead" + "noninhibitory"
- PROTAC + "non-inhibitory warhead"
- "covalent ligand" + "non-catalytic cysteine" + activity
能支持招募并保留某项功能，不代表配体单独完全无效；PROTAC/DUBTAC表型不能证明位点非功能。

### 机制与反证检索
- "steric occlusion" / "substrate access" / "substrate blocking"
- "induced inhibition" / "proximity-induced inhibition"
- "self-dimerization" + inhibition / substrate
- [配体名] + activation / inhibition / substrate / allosteric / transcription
- [位点或残基] + mutation / function / regulation / protein interaction
- [论文标题或DOI] + follow-up / correction / supporting information
确认新旧研究是否改变了早期“未知功能”的判断。

## 每个靶点的最小检索单元
1. 基因名＋常见蛋白名各搜；同源蛋白、isoform和工程化构建体不得混用。
2. silent/non-inhibitory/innocent 方向。
3. fragment/secondary-pocket/结构筛选方向。
4. 命中后回到具体化合物编号、主文、SI、PDB书目记录。
5. 反查该位点的功能与后续研究。
6. 没找到时记录搜索覆盖和信息限制，使用“未找到”，不用“不存在”。

## 文献中的PDB如何使用
优先记录所讨论配体与T的实验共结构；次选定位突变（需要折叠和基线功能对照）；再用MS/NMR/HDX等。
只记录PDB编号、文献所述残基/位点、构建体、物种、是否突变、作者发表的位点解释。
不下载坐标，不做结构计算、可视化叠合、距离测量或对接。
只有apo/其他配体/底物共结构时，标为“结构背景”，不提高到配体共结构等级。
作者只用NMR扰动映射在PDB上，仍属于NMR定位，不是T–L共晶。

## 后续批次建议
- 批次02：补首批关键SI与原文，优先β-catenin、PTP1B、OTUB1、PTPN2、USP7；再查磷酸酶池剩余成员及UCHL1/USP14/USP28。
- 批次03：激酶＋ATP/GTP酶、伴侣蛋白；结合数据库/fragment论文筛选，反查已知变构功能。
- 批次04：代谢酶、氧化酶及其他水解酶；优先真实底物体系和非活性位点小分子。
- 批次05：表观遗传酶、核酸加工酶。
- 批次06：PPI/核受体、E3扩展池；归并证据冲突并形成候选排序。
批次顺序可随证据调整。每批形成可阅读记录后再汇总；没有后台自动任务。

## 文献研究的交付终点
100个靶点均有可追踪的检索状态；最有希望的配体具备可复查证据链。
若找不到严格合格配对，交付B类（位点/功能属性未明）与C类（fragment/弱配体）及其具体缺口。
“诱导阻挡有潜力”只在已发表文献能支持时提出；其余标为未来待验证，不用本项目结构推演补齐。
